## 📌 الملخص التنفيذي

اللعبة في حالة **ممتازة كأساس**: منطق نقي قابل للاختبار (🧠 `GameBoard`)، محرك Flame مستقر (🎮 `BlockGame`)، واجهة كاملة (📱 `GameScreen`)، و13 اختباراً ناجحاً. ✅

أكبر الفجوات الحالية:

| 🔴 الفجوة | 📍 الموقع | 💥 الأثر |
|---|---|---|
| 🔇 الصوت معطّل تماماً | `sound_service.dart` + لا ملفات `assets/audio/` | تجربة ناقصة رغم وجود كل الكود |
| 🖼️ لا أصول بصرية | `assets/UI/` فارغ | هوية بصرية محدودة |
| 🎯 دوران مبسّط | `game_board.dart` → `rotate()` | إحساس غير احترافي للاعبين المخضرمين |
| 📤 لا مشاركة/تنافس | لا كود | ضعف الانتشار والاحتفاظ |
| 🌍 لغة واحدة ضمنياً | كل النصوص إنجليزية ثابتة | صعوبة التوسع |

**التوصية:** ابدأ بالفوز السريع (🔊 الصوت + ✨ Polish) ثم عمّق اللعب (🏆 SRS + 🎯 أوضاع) ثم وسّع الانتشار (📤☁️).

## 🎮 2. مقترحات أسلوب اللعب (Gameplay)

### 🥇 P0 — أساسي (تأثير عالٍ / جهد متوسط)

#### 1. 🏆 تطبيق SRS الحقيقي (Super Rotation System)
- **❓ لماذا:** اللاعبون المخضرمون يتوقعون سلوك T/J/L/S/Z الاحترافي قرب الجدران.
- **🛠️ كيف:** استبدال قائمة `kicks` الحالية بجداول `SRS-JLSTZ` و `SRS-I` و `SRS-O` حسب `from → to`، مع اختبارات لكل حالة.
- **📁 يمس:** `game_piece.dart` (تخزين `rotationFrom`) + `game_board.dart` → `rotate()`.
- **⏱️ الجهد:** 2-3 أيام + اختبارات.
- **📊 النجاح:** اختبار دوران ملاصق للجدار الأيمن/الأيسر والأرضية ينجح كما في Guideline.

#### 2. 🎯 أوضاع لعب إضافية
| الوضع | ⏳ القاعدة | 🎁 القيمة |
|---|---|---|
| 🏁 Sprint 40 | امسح 40 سطراً بأسرع وقت + عدّاد زمني | تحدٍّ قابل للمشاركة |
| ⚡ Ultra 2min | أعلى نقاط في دقيقتين | جلسات قصيرة مسببة للإدمان |
| 🌊 Zen | بلا نهاية لعبة، سرعة ثابتة | للاسترخاء وتجربة القطع |

- **🛠️ كيف:** `enum GameMode` + إعداد في `HomeScreen` + `fallIntervalSeconds(mode)` + حفظ أفضل نتيجة لكل وضع في `ScoreService`.
- **⏱️ الجهد:** 3-5 أيام.

#### 3. 🏅 نظام T-Spin والمكافآت المتقدمة
- كشف T-Spin (آخر حركة دوران + 3 زوايا محاصرة) ومنح `400/800/1200 × level`.
- رسوم `BACK-TO-BACK ×2` عند Tetris/T-Spin متتالية + نص احتفالي.
- **📁 يمس:** `game_board.dart` (`lockActivePiece` + `_applyScore`) + `block_game.dart` (صوت `Sfx.tetris` مميز).

### 🥈 P1 — مهم (تأثير متوسط / جهد منخفض-متوسط)

#### 4. 🎚️ مستويات صعوبة عند البدء
- 🐢 مبتدئ: سرعة أبطأ (`950ms`) + شبح إجباري + Lock Delay أطول `0.8s`.
- ⚔️ محترف: سرعة أسرع (`650ms`) + بلا شبح + نقاط `×1.5`.
- **🛠️ كيف:** `difficulty` في `GameSettings` + `fallIntervalSeconds` يقرأها + مضاعف نقاط.

#### 5. 👊 نظام الكومبو المرئي
- عدّاد `COMBO ×3 🔥` يظهر فوق اللوحة ويكبر مع السلسلة.
- اهتزاز تصاعدي + صوت متصاعد الطبقة كل كومبو.

#### 6. 📊 إحصائيات الجولة
- شاشة نهاية موسّعة: ⏱️ المدة، 🧱 القطع، ⚡ PPM (قطعة/دقيقة)، 🎯 T-Spins، 🔥 أعلى كومبو، 📈 مخطط النقاط.
- **📁 يمس:** `game_board.dart` (عدّادات) + `_GameOverOverlay`.

## 🔊 3. مقترحات الصوت والموسيقى (أول فوز سريع ⚡)

> 🔴 الوضع: كل الكود جاهز (`SoundService` يدعم 8 مؤثرات + موسيقى loop) لكن **صامت** — لا ملفات + `init()` بدون `assetsAvailable: true`.

### خطوات التفعيل (يوم واحد)

1. 🎵 تجهيز/شراء ملفات خفيفة (WAV قصيرة + MP3 حلقي):
   `move, rotate, drop, lock, clear, tetris, hold, game_over` + `music.mp3`.
2. 📦 إعلانها:
   ```yaml
   assets:
     - assets/UI/
     - assets/audio/
   ```
3. ⚡ التفعيل في `game_screen.dart:60`:
   ```dart
   await _sound.init(assetsAvailable: true);
   ```
4. 🎚️ إضافات مقترحة:
   - منزلق 🔊 مستوى الصوت + 🎵 الموسيقى في `SettingsScreen`.
   - 🎼 موسيقى تتسارع مع المستوى (طبقات أو `setPlaybackRate`).
   - 🔇 كتم تلقائي عند `pauseGame()` واستئناف عند `resumeGame()` (موجود جزئياً ✅).
   - 📳 مزامنة نبضة الاهتزاز مع إيقاع المسح الكبير.
